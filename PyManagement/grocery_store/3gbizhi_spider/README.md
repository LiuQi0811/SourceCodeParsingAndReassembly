# 3G壁纸全站爬虫使用说明

## ✨ 功能特性

- ✅ **无需登录**，直接下载无水印高清壁纸
- ✅ 支持全站爬取：手机壁纸、桌面壁纸、壁纸专题
- ✅ 自动分页，自动识别总页数
- ✅ 8线程多线程下载，速度快
- ✅ 断点续传：中断后重新运行自动跳过已下载
- ✅ 错误自动重试3次
- ✅ 自动分类保存，目录清晰
- ✅ 实时进度条显示
- ✅ 随机请求延迟，避免被封IP

## 🔍 逆向解密说明

网站图片分为两个版本：

1. **带水印预览图**：路径为 `/uploadmark/日期/hash.webp` - 页面主图显示，带3G壁纸水印，被压缩到650px宽
2. **无水印高清图**：路径为 `/uploads/日期/hash.webp` - **列表页** `lay-src` **属性直接暴露，不需要任何解密！**

爬虫直接从列表页提取 `lay-src` 属性的图片URL，绕过了详情页需要积分下载原图的限制，直接获取无水印高清版本。

## 🚀 快速开始

### 1. 环境依赖

`pip install requests tqdm`

### 2. 运行爬虫

`python 3gbizhi_spider.py`

### 3. 文件结构

`3G壁纸全站下载/`\

## ⚙️ 自定义配置

在代码开头 `配置` 区域可调整：

`THREAD_NUM = 8      # 下载线程数，建议5-10`\
`DELAY_MIN = 0.3     # 请求最小延迟(秒)`\
`DELAY_MAX = 1.0     # 请求最大延迟(秒)`

## 📌 注意事项

1. 图片格式为webp，是现代浏览器和手机都支持的高清格式，体积小质量高
2. 单张图片约30-80KB，分辨率476×780，手机使用足够清晰
3. 爬取速度适中，请勿将线程数设置过大，以免给服务器造成压力
4. 本爬虫仅供学习交流使用，请尊重网站版权
5. 默认只爬取手机壁纸和桌面壁纸两大主分类，如需爬取专题可取消代码中对应注释
