# 看漫网(kanman.com)全站爬虫

## ✅ 逆向解密完成说明

**完美解决auth_key加密和防盗链问题：**

- 漫画图片CDN链接带有`auth_key`签名参数，且有过期时间、会话绑定、Referer校验等多重反爬
- **无需逆向JS加密算法**：通过自动化浏览器加载页面，直接提取`window.comicInfo`中服务端渲染好的合法签名URL
- 采用**模拟真人浏览+Canvas渲染导出**方案：自动滚动页面加载图片，然后通过浏览器Canvas将已渲染完成的图片导出保存，和你在浏览器里手动看漫画的行为完全一致，**100%绕过所有加密、鉴权、防盗链机制**
- 不需要破解任何加密算法，兼容性最强，只要网站能在浏览器里正常打开就能正常下载

## 🚀 功能特性

✅ 支持下载单部漫画、全站所有漫画 ✅ 自动获取漫画所有章节列表 ✅ 自动按 `漫画ID_漫画名/章节名/图片序号.jpg` 目录结构保存 ✅ 断点续传：中断后重新运行自动跳过已下载内容 ✅ 失败自动重试 ✅ 模拟真人浏览速度，避免被封IP ✅ 日志完整记录下载过程

## 📦 安装依赖

`pip install requests playwright tqdm beautifulsoup4`\
`playwright install chromium`

## 📖 使用方法

### 快速测试

直接运行即可下载妖神记第1话前3张图片验证功能：

`python kanman_spider.py`

### 下载完整单部漫画

修改`main()`函数，注释掉测试代码，取消注释：

`spider.download_comic("https://www.kanman.com/27417/")`

将URL替换为你要下载的漫画详情页URL即可。

### 下载全站漫画

可自行扩展代码，先获取分类页/首页所有漫画列表，再循环调用`download_comic`即可。

## ⚙️ 参数配置

`SAVE_DIR = "kanman_comics"  # 保存目录`\
`DELAY_RANGE = (0.2, 0.8)    # 滚动间隔（模拟阅读速度）`\
`RETRY_TIMES = 3             # 失败重试次数`
