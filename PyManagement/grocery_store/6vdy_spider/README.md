# 6vdy 视频资源爬虫 + 下载器

针对 [6vdy.org](https://www.6vdy.org) 的全站影视资源抓取与视频下载工具。支持遍历全部分类、提取磁力/网盘/迅雷等下载链接，并通过 aria2c 实现磁力与 HTTP/FTP 资源的自动下载。

## 功能特性

- **全站抓取**：覆盖 14 个分类（电影 9 类 + 电视剧 4 类 + 综艺），自动分页遍历
- **多协议链接提取**：磁力 `magnet:`、迅雷 `thunder://`、ED2K、FTP、网盘（夸克/百度/阿里/115/迅雷网盘等，含提取码）
- **视频自动下载**：集成 aria2c，支持磁力（BT/P2P）、HTTP/HTTPS、FTP 多协议下载
- **迅雷链接自动解码**：Base64 解码 `thunder://` 专用链，还原真实 URL 后按协议下载
- **两种运行模式**：
  - `after`：全部采集完成后再统一下载（默认，适合先验证数据质量）
  - `stream`：边采集边下载（采集到一部即提交下载线程池，总耗时更短）
- **断点续爬 / 断点续下**：中断后重跑自动跳过已完成项
- **工程化**：随机 UA、请求间隔、失败重试、多线程并发、原始 HTML 备份
- **多格式输出**：JSON / CSV / Markdown 三种资源清单，下载报告 JSON

## 环境要求


## 快速开始

```bash
# 1. 克隆/进入项目目录
cd 6vdy_spider

# 2. 安装依赖（见上）

# 3. 默认运行：每分类前1页，全部采集后下载，每部最多下1个
python3 crawl_and_download.py

# 4. 边采集边下载模式
python3 crawl_and_download.py --mode stream

# 5. 只抓取不下载
python3 crawl_and_download.py --no-download

# 6. 只下载已抓取的数据（不重新爬取）
python3 crawl_and_download.py --download-only
```

## 命令行参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--mode {after,stream}` | `after` | 运行模式：`after`=全部采集后再下载，`stream`=边采集边下载 |
| `--categories` | 全部 | 指定分类，逗号分隔，如 `喜剧片,动作片,剧情片` |
| `--pages` | `1` | 每个分类抓取前几页 |
| `--max-dl` | `1` | 每部影片最多下载几个链接 |
| `--download-workers` | `2` | stream 模式下的并发下载线程数（磁力下载不建议太大） |
| `--no-download` | 关闭 | 只抓取资源信息，不下载视频 |
| `--download-only` | 关闭 | 只下载已抓取的 `movies.json`，不重新爬取（强制 after 模式） |
| `--output` | `./output` | 输出目录 |

## 运行模式详解

### after 模式（默认）

```
[========== 采集 ==========][========== 下载 ==========]
总耗时 = 采集时间 + 下载时间
```

先爬完所有影片信息并保存到 `movies.json`，再统一开始下载。适合：
- 先检查数据质量和链接完整性
- 网络不稳定时确保元数据先到手
- 需要人工筛选后再下载

### stream 模式

```
[========== 采集 ==========]
[  下载线程池 →→→→→→→→→→→→→→→→→→→→→→→→]
总耗时 ≈ max(采集时间, 下载时间)
```

每解析完一部影片的详情页，立即提交到独立的下载线程池，采集线程不阻塞，继续抓取下一部。适合大批量抓取，总耗时更短。

- 下载在 `ThreadPoolExecutor` 中并发执行，线程数由 `--download-workers` 控制
- 下载报告线程安全更新，每完成一部即持久化到 `download_report.json`
- 重复提交自动去重，已下载标题自动跳过

## 下载协议支持

| 链接类型 | 下载方式 | 自动下载 | 说明 |
|----------|----------|----------|------|
| 磁力 `magnet:` | aria2c (BT/P2P) | ✅ | 速度取决于做种人数，新片快、老片可能慢 |
| 迅雷 `thunder://` | 自动解码 → 按真实协议 | ✅ | Base64 解码还原真实 URL（可能是磁力/HTTP/FTP） |
| HTTP/HTTPS 直链 | aria2c（多线程）/ curl | ✅ | aria2c 优先，8 线程分块下载 |
| FTP/FTPS | aria2c / curl | ✅ | 原生支持 |
| ED2K `ed2k://` | 需 eMule 客户端 | ⚠️ 仅记录 | 不自动下载，链接保存在资源清单中 |
| 网盘（夸克/百度/阿里/115等） | 需网盘客户端/登录 | ⚠️ 仅记录 | 保存链接和提取码，需手动用网盘客户端下载 |

> **关于磁力下载**：磁力链接是 P2P 下载，aria2c 需要先通过 DHT 网络发现 peers、下载 .torrent 元数据、连接做种者后才开始实际传输。冷门资源可能速度很慢甚至无速度，属 BT 网络固有特性。

## 配置说明

核心配置位于 `spider_6vdy.py` 顶部：

```python
BASE_URL = "https://www.6vdy.org"       # 目标站点
MAX_WORKERS = 3                           # 采集并发线程数
MIN_SLEEP = 0.5                           # 请求最小间隔（秒）
MAX_SLEEP = 1.5                           # 请求最大间隔（秒）
TIMEOUT = 20                              # 请求超时（秒）
MAX_RETRY = 3                             # 请求失败重试次数
```

下载配置位于 `downloader.py` 顶部：

```python
DOWNLOAD_TIMEOUT = 3600                   # 单个下载任务最大时长（秒），默认1小时
MAX_RETRY = 2                              # 下载失败重试次数
```

输出目录可通过环境变量覆盖：

```bash
export 6VDY_OUTPUT="/path/to/custom/output"
python3 crawl_and_download.py
```

## 注意事项

1. **目标站点可达性**：6vdy.org 为非正规影视站点，可能存在域名变更、DNS 污染或被屏蔽的情况。如无法访问，请检查网络或确认最新域名。
2. **磁力下载速度**：BT/P2P 下载速度取决于做种人数和网络环境，不保证所有资源都能全速下载。
3. **网盘资源**：夸克、百度等网盘链接需登录鉴权，本工具仅保存链接和提取码，不自动下载。
4. **磁盘空间**：影视文件体积较大（单部 1-10GB），批量下载前请确保磁盘空间充足。
5. **合理控制并发**：采集并发 `MAX_WORKERS` 和下载并发 `--download-workers` 不宜过大，避免对目标站点和本地网络造成压力。
6. **法律风险**：本工具仅用于技术学习和研究。下载和传播受版权保护的影视内容可能违反相关法律法规，请使用者自行承担风险。
