# 宝藏图库全站爬虫使用说明

## 🔍 逆向分析结论

**该网站没有任何加密机制！** 无需复杂逆向破解：

1. **图片URL规律**：缩略图URL带 `small` 前缀，直接去掉前缀即可获得4K原图
   - 缩略图：`/d/file/p/20260908/small7195565d7949e0c0f5182d7b833b544e.jpg`
   - 原图：`/d/file/p/20260908/7195565d7949e0c0f5182d7b833b544e.jpg`（3840×2160）

2. **网站架构**：帝国CMS建站，URL结构规则清晰
3. **反爬机制**：无JS加密、无登录验证、无Cookie校验、无Referer严格校验

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `baozangtuku_spider.py` | 完整全站爬虫主程序 |
| `test_spider.py` | 快速测试脚本（验证功能用） |
| `使用说明.md` | 本说明文档 |

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install requests beautifulsoup4 tqdm
```

### 2. 运行测试（推荐先测试）
```bash
python test_spider.py
```
会下载1张测试图片验证功能是否正常。

### 3. 运行完整全站抓取
```bash
python baozangtuku_spider.py
```

## ⚙️ 配置说明

在 `baozangtuku_spider.py` 头部可修改以下参数：

```python
MAX_WORKERS = 5      # 并发下载线程数，建议3-10
MAX_PAGES = 0        # 0=抓取所有页，设置数字如10则每个分类只抓10页
DELAY_MIN = 0.5      # 请求最小延迟（秒）
DELAY_MAX = 1.5      # 请求最大延迟（秒）
```

## 💡 功能特性

- ✅ **自动去重**：已下载的文件不会重复下载
- ✅ **断点续传**：中断后重新运行会跳过已下载文件
- ✅ **多线程下载**：5线程并发加速
- ✅ **进度显示**：实时显示下载进度条
- ✅ **错误重试**：失败自动重试3次
- ✅ **随机延迟**：模拟真人浏览，避免被封
- ✅ **自动分类**：按网站分类自动建文件夹
- ✅ **文件名清理**：自动处理非法字符

## ⚠️ 注意事项

1. 仅供学习交流使用，下载的图片版权归原网站所有
2. 建议不要把线程数开太大（建议≤10），避免给服务器造成压力
3. 如遇网络问题中断，重新运行即可自动继续下载
4. 全站下载约需数小时（取决于网速），请耐心等待

## 📊 预计规模

- 总容量约50-200GB
- 如不需要全部下载，可修改 `MAX_PAGES` 参数限制页数
