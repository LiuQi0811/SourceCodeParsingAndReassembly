# ncat22.com 全站爬虫使用说明

## 功能特性

- **自动绕过CDN反爬**：使用 DrissionPage 控制真实浏览器，自动通过 cdndefend/Cloudflare 等 JS 验证
- **全站遍历**：BFS 广度优先爬虫，自动发现和爬取站点内所有页面
- **断点续爬**：自动保存进度，中断后再次运行可从断点继续
- **资源下载**：自动下载图片、CSS、JS、字体、视频等静态资源
- **智能去重**：自动去重，避免重复爬取
- **深度/页数控制**：可配置最大爬取深度和最大页数
- **并发友好**：可配置请求间隔，避免给服务器造成压力
- **自动保存**：按原网站目录结构保存，便于离线浏览
- **失败记录**：自动记录失败URL方便后续重试
- **站点地图**：爬取完成自动生成 sitemap.txt

## 环境准备

### 1. 安装 Python
确保已安装 Python 3.8+，可使用以下命令检查：
```bash
python --version
```

### 2. 安装依赖
```bash
pip install DrissionPage requests beautifulsoup4
```

使用国内源加速：
```bash
pip install DrissionPage requests beautifulsoup4 -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> **注意**：首次运行时，DrissionPage 会自动下载 Chromium 浏览器，请保持网络通畅。
> 如果已有 Chrome/Edge 浏览器，也会自动识别使用。

## 使用方法

### 基础使用（推荐）
使用带浏览器的模式，自动通过 CDN 验证：
```bash
python ncat22_spider.py https://www.ncat22.com/
```

### 常用参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| `-o, --output` | 指定输出目录 | `-o ./my_site` |
| `-d, --depth` | 最大爬取深度（0=无限） | `-d 3` 表示只爬3层 |
| `-m, --max-pages` | 最大爬取页数（0=无限） | `-m 100` 只爬100页 |
| `--delay` | 请求间隔秒数 | `--delay 2` 每次间隔2秒 |
| `--no-resources` | 不下载静态资源 | 只爬HTML页面 |
| `--headless` | 无头模式（浏览器后台运行） | 服务器环境使用 |
| `--timeout` | 超时时间（秒） | `--timeout 60` |
| `--simple` | 简单模式（纯requests，无浏览器） | 无反爬站点使用 |

### 使用示例

```bash
# 1. 完整爬取全站（推荐新手使用）
python ncat22_spider.py https://www.ncat22.com/

# 2. 后台无头模式爬取
python ncat22_spider.py https://www.ncat22.com/ --headless

# 3. 限制只爬100页，深度3层
python ncat22_spider.py https://www.ncat22.com/ -m 100 -d 3

# 4. 只爬HTML，不下载图片/CSS/JS
python ncat22_spider.py https://www.ncat22.com/ --no-resources

# 5. 放慢速度，间隔2秒请求一次
python ncat22_spider.py https://www.ncat22.com/ --delay 2

# 6. 指定输出目录
python ncat22_spider.py https://www.ncat22.com/ -o D:/website_backup
```

## 输出结构

爬取完成后，文件将保存在 `output/www.ncat22.com/` 目录下，结构如下：

```
output/www.ncat22.com/
├── index.html              # 首页
├── about/
│   └── index.html          # 关于页面
├── css/
│   └── style.css           # 样式文件
├── js/
│   └── main.js             # JS文件
├── images/
│   ├── logo.png            # 图片资源
│   └── banner.jpg
├── .crawl_progress.json    # 爬取进度（断点续爬用）
├── sitemap.txt             # 站点地图（所有爬取的URL列表）
├── failed_urls.txt         # 爬取失败的URL列表
└── spider.log              # 运行日志
```

## 断点续爬

爬虫运行过程中，每爬取10页会自动保存进度到 `.crawl_progress.json`。
如果中途中断（如关闭程序、网络断开），再次运行相同命令会自动从断点继续，无需重新爬取。

如需从头开始爬取，删除输出目录或删除 `.crawl_progress.json` 文件即可。

## 反爬说明

该网站使用了 **cdndefend** CDN防护，会先返回一个执行JS验证的页面，验证通过后设置Cookie才能正常访问。

本爬虫使用 **DrissionPage** 控制真实浏览器：
1. 自动打开浏览器访问网站
2. 等待页面执行JS验证代码
3. 验证通过后自动获取页面内容
4. 将Cookie同步到requests会话，用于后续下载静态资源

这种方式可以绕过绝大多数基于JS的CDN反爬验证。

## 常见问题

### Q1: 提示缺少 DrissionPage
执行安装命令：
```bash
pip install DrissionPage
```

### Q2: 浏览器打不开/启动失败
可以尝试：
1. 升级 DrissionPage 到最新版：`pip install -U DrissionPage`
2. 确保系统已安装 Chrome 或 Edge 浏览器
3. Linux 服务器可使用 `--headless` 无头模式

### Q3: 爬取速度慢
- 可以减小 `--delay` 参数，但建议不要设置为0，避免被封IP
- 可以先小范围测试：`-m 20 -d 2` 确认能正常爬取再放开限制

### Q4: 很多页面失败
- 适当增大 `--timeout` 超时时间
- 增大 `--delay` 请求间隔
- 检查网络连接是否正常

### Q5: 如何只爬特定路径？
目前版本会爬取整个域名下的内容。如需只爬特定路径，可修改代码中 `_normalize_url` 方法，添加路径过滤逻辑。

## 扩展开发

代码结构清晰，便于二次开发：

- `SiteCrawler` 类：主爬虫实现，可继承扩展
- `_fetch_page_browser()`：获取页面逻辑，可添加代理、UA轮换等
- `_extract_links()`：链接提取，可添加自定义提取规则
- `_save_content()`：内容保存，可改为存入数据库
