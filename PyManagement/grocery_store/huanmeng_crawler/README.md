# 幻梦ACG全站爬虫使用说明

## 网站信息
- 目标网站: https://www.huanmengacg.com/
- 网站类型: 轻小说在线阅读站
- 反爬分析: **无JS加密！纯服务端渲染HTML**，仅需基础UA+Referer伪装即可正常访问

## 逆向分析结论

### ✅ 无加密解密需求
经过详细分析，该网站没有以下常见加密手段：
1. ❌ 无JavaScript动态加密/混淆正文
2. ❌ 无字体反爬（CSS自定义字体加密）
3. ❌ 无AES/RSA等接口参数加密
4. ❌ 无Cookie反爬（不需要JS生成Cookie）
5. ❌ 无Canvas指纹识别
6. ❌ 无验证码拦截

### ⚠️ 基础反爬措施
网站仅做了以下简单检测，爬虫中已完美处理：
1. **User-Agent检测**: 必须使用移动端UA（桌面端UA返回"书籍下架"）
2. **Referer检测**: 爬取章节时需要带详情页Referer
3. **请求频率检测**: 随机延时1-2.5秒即可绕过

## 文件说明

| 文件 | 说明 |
|------|------|
| `huanmeng_spider.py` | 全站爬虫主程序 |
| `test_single.py` | 单本小说测试脚本（快速验证用） |
| `novels/` | 小说保存目录（自动创建） |
| `progress.json` | 断点续传进度文件（自动生成） |
| `spider.log` | 爬取日志（自动生成） |

## 安装依赖

```bash
pip install requests beautifulsoup4
```

## 使用方法

### 1. 快速测试（单本小说）
```bash
python test_single.py
```
这会爬取《无职转生》第一章作为测试。

### 2. 全站爬取
```bash
python huanmeng_spider.py
```

### 3. 爬取配置
打开 `huanmeng_spider.py` 修改顶部配置：
```python
MAX_PAGES = 0        # 0=爬全部225页, 设置5则只爬前5页
DELAY_MIN = 1.0      # 请求最小间隔(秒)
DELAY_MAX = 2.5      # 请求最大间隔(秒)
```

## 输出格式

## 特色功能

1. ✅ **断点续传**: 中途停止下次运行自动从上次位置继续
2. ✅ **自动重试**: 网络失败自动重试3次（指数退避）
3. ✅ **智能限速**: 随机延时1-2.5秒，避免被封IP
4. ✅ **广告清理**: 自动移除网站广告、水印、版权声明等无关内容
5. ✅ **编码处理**: 自动处理UTF-8编码，避免乱码
6. ✅ **进度保存**: 每爬完一章/一本自动保存进度，不怕崩溃
7. ✅ **详细日志**: 控制台+文件双日志输出

## 注意事项

1. 全站约有 **4000+本小说**，全部爬取耗时较长（约10-20小时）
2. 建议先运行 `test_single.py` 确认环境正常
3. 可设置 `MAX_PAGES = 3` 先爬前3页测试
4. 如遇IP被封，暂停30分钟后再运行即可（断点续传会自动跳过已爬内容）
