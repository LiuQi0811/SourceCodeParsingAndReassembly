# 老画报网全站爬虫使用说明

## 网站信息

- **目标网站**: http://www.laohuabao.com/
- **网站类型**: 老画报、连环画、小人书在线欣赏
- **加密情况**: **无加密**，无需逆向解密！图片URL可通过规则直接转换为高清原图
- **图片路径规律**:
    - 缩略图路径: `/thumb/xxx.jpg` 或 `/smallpic/xxx.jpg`
    - 高清原图: 去掉 `/thumb/` 或 `/smallpic/` 目录即可直接访问

## 文件说明

- `laohuabao_spider.py` - 全站爬虫主程序

## 功能特点

✅ 自动遍历全站所有分类、分页 ✅ 自动下载**高清原图**（非缩略图） ✅ 断点续传：中断后可继续，不会重复下载 ✅ 多线程并发下载，速度更快 ✅ 自动去重 ✅ 完整的错误重试机制 ✅ 随机请求延迟，避免被封IP ✅ 支持两种模式：全站爬取 / 单本下载

## 使用方法

### 1. 环境准备

`pip install requests beautifulsoup4`

### 2. 全站爬取（下载整个网站所有内容）

`python laohuabao_spider.py`

- 下载的文件会保存在 `老画报网全站下载/` 目录
- 按网站分类目录结构自动整理
- 可以随时按 `Ctrl+C` 中断，下次运行自动继续

### 3. 只下载单本画册

`python laohuabao_spider.py single <画册URL>`

示例：

`python laohuabao_spider.py single http://www.laohuabao.com/xiaorenshu/mingzhu/ymyaq/142029350.html`

## 配置说明（代码开头可修改）

`MAX_WORKERS = 5      # 并发下载线程数，建议不要超过10`\
`DELAY_MIN = 0.5      # 请求最小延迟(秒)`\
`DELAY_MAX = 1.5      # 请求最大延迟(秒)`\
`MAX_RETRY = 3        # 失败重试次数`\
`RESUME_DOWNLOAD = True  # 是否断点续传`
