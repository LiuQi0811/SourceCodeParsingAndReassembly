# E站弹幕网 (www.ezdmw.org) 全站爬虫

针对 E站弹幕网 开发的全站结构化抓取工具，可批量抓取动漫番剧信息、磁力下载链接、社区文章、动漫图集、学习资源等内容。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `ezdmw_spider.py` | 主爬虫程序 |
| `extract_magnets.py` | 磁力链接提取工具（从已抓取数据导出磁力列表） |
| `ezdmw_data/` | 数据输出目录（运行后自动生成） |

## 功能特性

- ✅ **动漫番剧全量抓取**：自动遍历首页推荐、分类列表（热血/后宫/漫改/轻改等30+分类）、年份归档、排行榜等入口
- ✅ **详情信息完整提取**：标题、类型标签、年份、连载状态、总集数、每集播放链接、全部磁力下载链接、简介、剧情
- ✅ **多栏目覆盖**：动漫番剧 + 社区文章 + 动漫图集（含图片链接） + 学习园地资源
- ✅ **智能反爬**：随机 User-Agent、请求随机间隔（0.8-2秒）、失败自动重试3次
- ✅ **断点续爬**：实时保存进度，中断后再次运行自动跳过已抓页面
- ✅ **多线程并发**：默认3线程，可通过 `--workers` 调整
- ✅ **数据结构化**：JSON 格式保存，方便二次处理
- ✅ **磁力链接一键导出**：自动整理为 TXT（易读）和 CSV（表格导入）两种格式

## 快速开始

### 1. 安装依赖

`pip install requests beautifulsoup4`

### 2. 运行爬虫

`# 全量抓取（动漫 + 社区 + 图集 + 学习资源，推荐）`\
`python ezdmw_spider.py`\
\
`# 只抓动漫番剧（速度最快，核心需求）`\
`python ezdmw_spider.py --anime-only`\
\
`# 指定并发数和翻页上限`\
`python ezdmw_spider.py --workers 5 --max-pages 100`

### 3. 提取磁力链接

`# 提取全部动漫磁力`\
`python extract_magnets.py`\
\
`# 只提取标题包含"从零开始"的动漫磁力`\
`python extract_magnets.py --anime "从零"`

## 命令行参数

### 主爬虫 (ezdmw_spider.py)

| 参数 | 说明 |
| --- | --- |
| `--anime-only` | 只抓取动漫番剧，跳过社区/图集/学习资源 |
| `--max-pages N` | 每个分类列表最大翻页数，默认 200（足够覆盖全站） |
| `--workers N` | 并发线程数，默认 3（建议不超过5，避免给站点造成压力） |
| `--force` | 强制重新抓取已存在的页面（默认跳过） |

### 磁力提取 (extract_magnets.py)

| 参数 | 说明 |
| --- | --- |
| `--anime 关键词` | 只导出标题包含指定关键词的动漫磁力 |
| `--output-dir 路径` | 指定数据目录 |

## 输出文件结构

`ezdmw_data/`\
`├── anime.json          # 动漫番剧数据（核心）`\
`├── community.json      # 社区文章`\
`├── atlas.json          # 动漫图集（含图片URL）`\
`├── learning.json       # 学习园地资源`\
`├── visited_urls.json   # 已访问URL记录（断点续爬用）`\

`└── magnets.csv         # 磁力链接（表格格式，可直接用Excel打开）`

## 爬取范围

程序自动发现并遍历以下入口页面：

- **动漫列表**：首页推荐、动漫综合页、追番页、补番推荐、完结动画、动漫电影
- **分类标签**：轻改/漫改/游改/原创/热血/战斗/魔法/后宫/恋爱/校园/日常/搞笑/百合/萌系等30+分类
- **年份归档**：从2010年至2026年各年新番
- **排行榜**：月排行、总排行、各分类排行
- **社区内容**：综合社区、文章、佳句、问答、漫评
- **图集资源**：动漫图集、壁纸、表情、头像
- **学习园地**：各类学习资源（视频教程、软件资料等）

## 注意事项

1. **合理使用**：本工具仅供学习交流使用，请遵守网站robots规则和相关法律法规
2. **请求频率**：默认已设置 0.8-2秒 随机延迟，建议不要过度调高并发数
3. **断点续爬**：运行中按 `Ctrl+C` 中断会自动保存进度，再次运行即可继续
4. **全量抓取耗时**：全站完整抓取约需几十分钟到数小时（视网络状况），首次运行可先用 `--max-pages 10` 小规模测试
5. **数据更新**：新番持续更新，可定期重新运行爬虫增量抓取新内容
