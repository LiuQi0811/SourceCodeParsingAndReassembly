## 安装依赖

```bash
pip install requests
```

## 使用方法

### 1. 查看所有分类
```bash
python dytt_crawler.py --list-types
```

### 2. 快速全站抓取（默认配置）
```bash
python dytt_crawler.py
```

### 3. 自定义参数抓取
```bash
# 10线程并发，请求间隔0.2秒，输出到data目录
python dytt_crawler.py -w 10 -d 0.2 -o ./data

# 只输出CSV格式
python dytt_crawler.py -f csv

# 每页100条(最大)，加快速度
python dytt_crawler.py -p 100
```

### 4. 按分类抓取
```bash
# 只抓取国产剧(分类ID=13)
python dytt_crawler.py -t 13

# 抓取电影片+动作片+喜剧片
python dytt_crawler.py -t 1,6,7
```

## 命令行参数说明

| 参数 | 缩写 | 默认值 | 说明 |
|------|------|--------|------|
| --output | -o | ./output | 输出文件目录 |
| --workers | -w | 5 | 并发线程数 |
| --delay | -d | 0.3 | 请求间隔(秒)，越小越快但容易被封 |
| --pagesize | -p | 50 | 每页条数，最大100 |
| --type | -t | None | 指定分类ID，多个用逗号分隔 |
| --format | -f | both | 输出格式：json/csv/both |
| --list-types | | | 列出所有分类后退出 |

## 功能特性

- ✅ **多线程并发**: 支持多线程加速采集
- ✅ **断点续传**: 异常中断后再次运行可从断点继续，不会重复抓取
- ✅ **自动重试**: 请求失败自动重试3次
- ✅ **双重格式输出**: 同时生成JSON(完整数据)和CSV(便于Excel打开)
- ✅ **进度显示**: 实时显示抓取进度、速度、预计剩余时间
- ✅ **分类筛选**: 支持只抓取指定分类
- ✅ **自动去重**: 基于vod_id自动去重

## 输出文件

程序运行后将在输出目录生成：
- `dytt_videos_YYYYMMDD_HHMMSS.json` - 完整JSON数据
- `dytt_videos_YYYYMMDD_HHMMSS.csv` - CSV表格数据（可用Excel打开）
- `.checkpoint.json` - 断点续传记录（隐藏文件）

## 性能预估

在默认配置(5线程、0.3秒间隔、每页50条)下：
- 速度约: 30-50条/秒
- 全量抓取约: 30-60分钟

调整为10线程、0.1秒间隔、每页100条：
- 速度约: 150-200条/秒
- 全量抓取约: 7-10分钟

## 注意事项

1. 请合理控制并发速度，避免对站点造成过大压力
2. 建议请求间隔不小于0.1秒
3. 抓取的数据仅供个人学习研究使用，请勿用于商业用途
4. 如遇连接失败，可适当增大delay参数
