# 电影港 (dygang.tv) 全站爬虫使用说明

## 网站分析结果

✅ **无复杂JS加密/混淆**：经逆向分析，该网站下载链接直接以明文形式出现在HTML中，无需解密
✅ **编码**：GB2312/GBK编码，爬虫已自动处理
✅ **链接类型**：磁力链接(magnet:)、迅雷链接(thunder://)、电驴(ed2k://)、FTP、百度网盘、夸克网盘、迅雷网盘、阿里云盘
✅ **系统**：帝国CMS(EmpireCMS)，分页格式为 `index_N.htm`

## 逆向分析说明

经过对网站JS文件的分析：
- `/jtrtytcdz45yfh3456.js`：仅做移动端UA检测跳转，无加密逻辑
- `/1endsd5643.js`：实际为404页面
- 页面中下载链接直接写入`<a>`标签的`href`属性，无异步加载、无加密字符串、无动态生成
- 无需执行JS、无需解密算法、无需破解签名

## 文件说明

- `dygang_crawler.py`：完整全站爬虫代码
- `电影港全站数据/`：抓取结果目录
  - `电影详情/`：每部电影单独保存JSON文件（含完整信息+下载链接）
  - `下载链接/`：汇总文件
    - `全部下载链接汇总.csv`：所有下载链接CSV表格
    - `*_磁力链接.txt`：按分类整理的TXT文件，可直接复制到迅雷等下载器
  - `电影信息总表.csv`：所有影片的基础信息表格
  - `全站电影数据完整.json`：所有数据的完整JSON
  - `爬虫日志.log`：运行日志

## 使用方法

### 环境准备
```bash
pip install requests beautifulsoup4
```

### 运行爬虫
```bash
python dygang_crawler.py
```

### 全量爬取设置

打开 `dygang_crawler.py`，找到第322行：
```python
MAX_PAGES_PER_CATEGORY = 3  # 每个分类爬取前N页，改为None爬全部
```

- 改为 `None` = 爬取全站所有页面
- 最新电影分类目前约1290页，全部13个分类全量爬取预计：
  - 总电影数：约20000~30000部
  - 耗时：约3~6小时（取决于网络和线程数）
  - 可调整 `MAX_WORKERS` 参数加快速度（建议不超过10）

## 输出字段说明

- title：电影名称
- category：分类
- year：年代
- country：国家/地区
- genre：类型
- language：语言
- douban_rating：豆瓣评分
- director：导演
- actors：主演列表
- description：剧情简介
- cover：封面图URL
- download_links：下载链接列表（磁力/迅雷/ed2k/ftp）
- pan_links：网盘链接列表（含提取码）

## 注意事项

1. **仅供学习交流使用**，请遵守相关法律法规和网站robots协议
2. 建议设置合理请求间隔，避免对服务器造成过大压力
3. 网站结构可能发生变化，如失效需微调选择器
4. 部分老电影可能无网盘链接，只有磁力链接
5. 可导入支持磁力链接的下载器（如迅雷、qBittorrent、BitComet等）下载
