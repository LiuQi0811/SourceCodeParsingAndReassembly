# 图灵社区爬虫使用说明

## ⚠️ 重要法律声明（请务必阅读）

1. **禁止破解付费内容**：本项目**绝对不包含**任何逆向解密、破解DRM、下载付费电子书的功能，也不会提供相关技术支持。
2. **版权保护**：图灵社区所有图书内容（包括电子书、付费文章等）均受《中华人民共和国著作权法》保护，未经授权的复制、传播、破解行为属于违法行为，将承担相应法律责任。
3. **合规使用**：本爬虫仅用于学习交流，仅抓取网站**公开展示**的元数据信息（书名、作者、定价、公开简介等）。
4. **授权要求**：如需大规模爬取或商业使用数据，请直接联系图灵社区官方获得授权。
5. **正版支持**：请支持正版图书，可通过图灵社区官网（https://www.ituring.com.cn/）购买正版纸质书或电子书。

## 功能说明

本合规爬虫实现以下功能：
- ✅ 抓取图书公开展示的元数据（书名、作者、译者、ISBN、定价、出版日期、公开简介等）
- ✅ 下载公开可访问的图书封面图片
- ✅ 自动随机延迟，避免给服务器造成压力
- ✅ 数据导出为JSON和CSV格式
- ❌ **不包含**任何付费内容下载、破解、解密功能
- ❌ **不会**尝试绕过网站登录验证或付费墙
- ❌ **不会**抓取任何需要购买后才能查看的内容

## 环境配置

```bash
# 安装依赖
pip install requests beautifulsoup4
```

## 使用方法

```bash
# 运行爬虫
python turing_community_spider.py
```

## 输出说明

爬取的数据将保存在 `turing_public_data/` 目录下：
- `books_public_info.json` - JSON格式的图书公开信息
- `books_public_info.csv` - CSV格式的图书公开信息（可直接用Excel打开）
- `covers/` - 图书封面图片目录

## 爬虫礼仪说明

本爬虫严格遵守网络爬虫礼仪：
1. 设置合理的User-Agent，明确标识爬虫身份
2. 请求间隔设置为2-5秒随机延迟，避免高频访问
3. 仅爬取公开可访问的页面，不尝试访问受限内容
4. 不做分布式爬取，不对网站造成流量压力

## 为什么不能提供全站下载和逆向解密？

1. **法律风险**：破解版权保护措施、未经授权下载受版权保护的内容属于违法行为，最高可处三年以上七年以下有期徒刑，并处罚金。
2. **知识产权尊重**：作者、译者和出版社花费大量心血创作和出版图书，盗版行为严重损害创作者权益。
3. **技术边界**：作为AI助手，我不能协助任何可能违反法律法规、侵犯他人合法权益的行为。
