# 需求文档

## 1. 应用概述

### 1.1 应用名称
yt-dlp Web 可视化工作台

### 1.2 应用描述
一款基于 Web 端、面向音视频下载需求的可视化配置与命令生成工具。系统完整复刻 yt-dlp 的核心选项体系与处理工作流，提供 URL 视频信息预览、音视频格式可视化选择、全量参数可视化配置、命令行实时双向生成与一键复制、预设模板管理及参数帮助检索等功能，降低命令行工具的使用门槛并提高配置准确性。

## 2. 用户与使用场景

### 2.1 目标用户
- 常用 yt-dlp 命令行但难以记忆复杂参数标志的音视频下载用户
- 需要针对不同网站快速定制下载画质、音轨、字幕、后处理规则的用户
- 需要批量管理下载参数预设与任务清单的用户

### 2.2 核心使用场景
- **单视频/列表快速解析与命令生成**：输入视频链接，查看基础元数据预览，可视化勾选画质与格式，即时获取并复制可执行命令行。
- **高级参数定制与预设复用**：配置网络代理、身份凭证、字幕嵌入、音频提取、章节切分等复杂选项，保存为常用配置预设，便于后续直接调用。
- **批量任务构建与导出**：添加多条链接与各自配置，生成批处理命令脚本或配置参数文件。
- **选项语义查询与学习**：在内置帮助文档中检索 yt-dlp 的参数作用、取值规则与示例。

## 3. 页面结构与功能说明

### 3.1 页面结构

- 工作台主页
  - URL 输入与元数据预览区
  - 快速格式与下载模式选择器
  - 命令行实时生成与操作面板
- 选项配置中心（全量参数面板）
  - 通用与网络配置
  - 视频/音频选择与过滤
  - 下载与重试控制
  - 文件系统与命名模板
  - 字幕与元数据
  - 章节与后处理/转码
  - 身份验证与 Cookies
- 预设管理页面
  - 预设列表
  - 预设创建/编辑/应用/导入导出
- 批量任务管理页面
  - 任务列表与状态模拟
  - 批量命令/脚本导出
- 参数帮助文档与速查
  - 选项检索与分类浏览
  - 常用场景示例模版

### 3.2 功能说明

#### 3.2.1 工作台主页
- **URL 输入与元数据解析**：
  - 支持输入单个视频链接、播放列表链接或频道主页链接。
  - 支持通过公共元数据接口解析并展示基础视频信息（标题、封面图、作者/频道名、视频时长等）。
  - 提供 URL 有效性基础校验与解析状态提示。
- **快速格式选择器**：
  - 提供常见清晰度等级选择（最佳画质、4K/2K/1080P/720P/480P、仅音频最高音质、特定音频格式 MP3/M4A/FLAC/WAV 等）。
  - 自动将快速选择转化为对应的 `-f` / `--format` 表达式与 `--extract-audio` 等参数。
- **命令行实时生成面板**：
  - 根据当前 URL、格式选择器及高级配置项，实时渲染拼接完整的 yt-dlp 命令行。
  - 支持针对 Windows (CMD / PowerShell)、macOS / Linux (Bash / Zsh) 的跨平台转义语法切换显示。
  - 提供一键复制命令、保存为当前任务、下载为 `.bat` / `.sh` 执行脚本功能。

#### 3.2.2 选项配置中心（高级参数）
- **分类表单组织**：
  - **通用与网络**：配置超时时间、代理服务器（HTTP/SOCKS5）、限速速率、IPv4/IPv6 首选等。
  - **视频/音频过滤**：自定义格式过滤字符串、视频编码（H.264/AV1/VP9）、音频编码、首选容器封装（MP4/MKV 等）。
  - **文件命名与路径**：输出目录配置、输出文件名模版变量插入（如 `%(title)s.%(ext)s`、`%(upload_date)s` 等）、文件覆盖策略。
  - **字幕与元数据**：自动生成字幕/官方字幕选择、字幕语言代码、字幕转格式（SRT/VTT）、嵌入字幕到容器、嵌入元数据/视频封面。
  - **后处理与切分**：音频提取并重采样、章节拆分独立文件、视频剪切时间区间、外部下载器调用参数。
  - **身份凭证**：浏览器 Cookies 读取（Chrome/Firefox/Edge 等）、用户名密码配置、Netrc 配置。
- **参数联动与状态同步**：所有表单修改即时双向同步至工作台命令行预览。

#### 3.2.3 预设管理页面
- **预设存储与管理**：
  - 支持将当前配置中心的一套参数组合保存为具名预设（如「4K+外挂字幕最高画质」、「MP3音频最高音质提取」）。
  - 预设支持后端持久化存储，支持创建、重命名、编辑、删除。
  - 工作台可随时一键加载预设并覆盖当前配置。
- **预设导入与导出**：
  - 支持以 JSON 或 yt-dlp 配置文件格式（`.conf`）导出/导入预设。

#### 3.2.4 批量任务管理页面
- **批量任务构建**：
  - 支持多 URL 批量导入，为不同任务指定不同预设或统一配置。
  - 提供任务列表展示（链接、目标格式、输出配置、状态标记）。
- **批处理导出**：
  - 支持一键导出多条命令整合的批量执行脚本（Shell 脚本、Windows 批处理脚本）。
  - 支持生成 yt-dlp 输入批处理文本文件（`--batch-file` 适用格式）。

#### 3.2.5 参数帮助文档与速查
- **内置选项检索**：
  - 完整收录 yt-dlp 官方参数选项、长短标志、取值类型与语义解释。
  - 提供关键词搜索与按功能分类筛选。
  - 在帮助项中提供「应用到当前配置」快捷按钮。

## 4. 业务规则与核心逻辑

### 4.1 命令行生成与转义规则
1. **参数拼接顺序**：固定按照 `yt-dlp [通用参数] [网络参数] [视频/音频格式参数] [字幕/元数据参数] [后处理参数] [文件路径模板] [目标URL]` 的结构化顺序拼接输出。
2. **特殊字符与字符串转义**：
   - 包含空格、分号、特殊符号的文件名模版、代理地址或自定义格式表达式，自动用双引号或单引号包裹。
   - 针对 Windows 环境与 POSIX 环境自动处理通配符与转义符差异。
3. **冲突参数互斥消解**：
   - 当勾选「提取纯音频」时，自动禁用与视频编码强制转换相关的冲突配置项。
   - 快速格式模式与高级自定义 `-f` 字符串二选一优先，以当前最后修改的模式为准。

### 4.2 数据存储规则
1. 系统持久化存储用户自定义的配置预设与批量任务列表。
2. 预设数据需保存完整的参数键值映射表，以便无损反向渲染到 UI 控件中。

### 4.3 技术可行性与能力边界
1. **Web 端真实功能**：
   - 视频公开元数据解析与预览。
   - yt-dlp 全量选项的 UI 表单交互与状态管理。
   - 命令行与批处理脚本的实时精准生成、校验、格式化及导出。
   - 配置预设与批量任务数据的持久化存储与管理。
2. **执行边界说明**：
   - 媒体下载、格式转码与本地文件写入需由用户在本地终端运行生成的命令行或脚本完成，Web 应用本身不代理下载或转码音视频大文件。

## 5. 异常与边界情况

| 序号 | 异常/边界情况 | 系统处理逻辑 |
| :--- | :--- | :--- |
| 1 | 输入无效或无法解析的视频链接 | 提示 URL 格式无效或元数据解析失败，保留输入内容，允许用户直接生成基础命令行而不阻塞操作 |
| 2 | 用户在高级选项中填入非法字符或空参数 | 表单输入框进行格式校验，生成命令行时自动过滤无效空选项并高亮错误项 |
| 3 | 导入格式错误的外部预设 JSON/Conf 文件 | 终止导入操作，展示具体解析错误行或字段，不覆盖现有预设 |
| 4 | URL 中包含特殊字符（如 `&`、`?`、空格等） | 命令行生成器自动将 URL 进行规范化引用包裹，避免终端解析为后台任务或管道符 |
| 5 | 用户配置了相互冲突的参数组合 | UI 给出参数冲突警示说明，并在命令行中按 yt-dlp 官方推荐优先级规范生成 |

## 6. 验收标准

1. 用户在输入框粘贴有效视频链接后，能够正确展示对应的标题、时长等元数据预览。
2. 用户切换画质、音频提取、字幕嵌入等配置时，下方命令行展示区能够在 100 毫秒内完成实时更新与正确拼接。
3. 用户选择 Windows 或 Linux 平台后，生成的命令行转义符号正确无误，可直接复制至对应本地终端正常执行。
4. 用户能够成功创建、保存自定义参数预设，并在切换预设后准确重置配置面板表单值。
5. 用户在批量任务页面导入多条链接后，能够成功生成并导出包含多条有效命令的批处理脚本文件。
6. 用户可在帮助速查面板中按关键词检索到特定参数（如 `--cookies-from-browser`），并能将其一键应用到当前配置中。

## 7. 本期不实现功能

1. 服务端直接执行 yt-dlp 二进制进程进行音视频下载与转码。
2. 浏览器端直接进行大体积多媒体流的本地合成与封装处理。
3. 视频私有账号登录态的云端代理接管与自动化抓取。
