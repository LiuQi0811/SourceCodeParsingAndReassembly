# DESIGN.md

## 气质与意象
- 编辑器参考深夜设计工作台：深色金属灰外壳、低眩光面板、细密分隔线，中央画布像一张被精准照明的白纸。
- 整体气质专业、克制、工程化，强调结构层级与拖拽定位，不使用娱乐化渐变和夸张装饰。

## 视觉策略
- 三栏专业布局：顶部工具栏、240px 左侧物料、自适应浅色画布、280px 右侧检查器。
- 画布通过灰色工作台背景与白色页面形成明确层级；选中、悬浮、插入指示均使用细线和轻量标签。
- 图标与按钮以文字和极简几何形态为主，避免外部图片依赖。

## Design Tokens
### 色彩
- 编辑器底色：#0b0f14，面板色：#111821，悬浮面板：#18212c。
- 主强调色：#2f7df6，用于选中态、主按钮和关键指示线。
- 画布背景：#f4f6f8，页面底色：#ffffff。
- 主要文字：#e8edf4；次要文字：#93a1b0。
- 危险操作：#e5484d。

### 字体
- 中文优先：`"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, sans-serif`。
- 代码与 JSON 使用：`"SFMono-Regular", Consolas, "Liberation Mono", monospace`。

### 间距与圆角
- 面板内边距：12px；控件间距：8px。
- 面板卡片圆角：8px；按钮圆角：6px；画布页面圆角：10px。

## 动效与交互
- 控件过渡使用 120ms ease-out，拖拽时不做重动画，仅更新指示线位置。
- 选中框跟随组件外边缘，hover 态比选中态更轻。
- 属性修改必须即时、稳定地反馈到画布。

## 设计禁忌
- 不使用 React/Vue/Svelte/jQuery。
- 不使用蓝紫渐变、玻璃拟态、霓虹光效。
- 导出页面不得引用任何外部字体、图片、脚本或样式。
