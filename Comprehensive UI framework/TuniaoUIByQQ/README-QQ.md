# QQ 风格 H5 交互原型（TuniaoUI + uni-app）

基于本工程的 uni-app（Vue3 + TS + Vite）与 TuniaoUI 组件库，做的一套「最新版 QQ」风格的手机端交互原型：全部为 mock 数据，可切页、可发消息、未读角标联动，不接后端。

## 快速运行

```bash
# 1. 安装依赖（本工程 package.json 的 overrides 用了 $ 引用，必须加 --legacy-peer-deps）
npm install --legacy-peer-deps

# 2. 启动 H5
npm run dev:h5
```

浏览器打开控制台输出的地址（默认 5173，被占用时自动顺延，例如 5174）：

- 直接访问：`http://localhost:5174/`
- 首页是登录页：`/#/pages/qq/login/index`

演示账号已预填（QQ 号 `1000123456`，密码任意），勾选协议后点「登 录」即可进入。登录态写在本地 storage（key：`qq-demo-logged-in`），刷新不会掉登录；「我的 → 退出登录」可清除。

演示进度会自动保存到本地（key：`qq-demo-state`）：发消息、会话草稿、红包/转账状态、建群、置顶/免打扰、群待办/投票/签到、动态等操作刷新后仍在。想回到初始状态，去「设置 → 演示数据 → 重置演示数据」，会清空本地快照并刷新回消息页（登录状态保留）。

> 手机壳宽度固定 430px 居中，建议用 Chrome 设备模拟（iPhone 12/13，390~430 宽）观看，桌面直接看也可以。

## 可以玩什么

1. 登录页：点登录进入消息列表；「我的 → 退出登录」回到登录页。
2. 消息页：点会话进入聊天；左滑会话出现「置顶 / 免打扰 / 删除」，点空白处收起；顶部「+」进建群。
3. 聊天页：输入文字发送，对方会在 1.5s 后自动回一句；点笑脸开表情面板（点表情直接发出）；点「+」开面板——**图片**会弹出演示相册（6 张，点一张直接发出），**视频**发送一条封面 + 时长的视频消息，**红包 / 转账**打开金额面板（单聊可转账，群聊仅红包），**文件**直接发一条 PDF 文件消息，位置/名片为占位提示；切到语音模式，**按住「按住说话」→ 松手**发一条语音（不足 1s 会提示太短），语音气泡点一下会出现播放波纹动画。右上角电话 / 视频按钮会进入通话页。
4. 消息菜单：在消息气泡上右键（手机上长按）呼出菜单——复制 / 引用 / 多选 / 删除，自己的消息额外有「撤回」；撤回后原位显示“你撤回了一条消息”；引用后发送，气泡上方会带上被引用的原文。
5. 底部 Tab：消息 / 联系人 / 频道 / 动态 / 我的，未读角标由 store 统一计算，读消息后实时减少。
6. 联系人：右侧字母索引可跳转分组；点「新朋友」进入好友申请页——同意后对方立刻进入联系人、生成一条会话，联系人页角标同步减少。
7. 动态：右上角相机发布说说——写文字、选 1~4 张演示配图（超过会提示）、选择是否带位置；发表后立刻插到动态流顶部，同时进入「我的空间」，说说/照片统计同步 +1；点赞会即时变色并加数，点卡片进对应人空间。
8. 我的：点头像/资料进资料卡；八宫格进 QQ 空间、相册等；「设置」进设置页。
9. 搜索：输入关键词实时过滤好友/群/聊天记录；点历史或热搜词填充。
10. 扫一扫、QQ 空间、建群勾选等页面均可交互（mock）。
11. 群聊：进入「产品设计组」或「前端小分队」，聊天页顶部有群公告条；点公告条或右上角「…」进入群聊信息——可看群公告、成员、群文件，点击「群管理」进入群管理页；切换「消息免打扰 / 置顶聊天」（会同步到消息列表），点「退出群聊」二次确认后该会话从消息页移除。开启全员禁言后，聊天页顶部会出现提示，且普通成员发文字 / 图片 / 文件 / 语音都会被拦截。
12. 深色模式：「我的 → 设置 → 通用 → 深色模式」拨开关，整个 app（消息/聊天/联系人/动态/我的/各二级页）即时换成深色皮肤，刷新后保持；再关掉即回到浅色。
13. 群成员：群资料页点「全部 128 人」进入成员列表——按群主 / 管理员 / 群成员分组，顶部可搜索昵称，点任意成员进他的资料卡；群资料页成员头像同样可点。
14. 群文件：群资料页点「全部文件」或任意一条文件进入群文件页——顶部汇总群名 / 文件数 / 总大小，搜索框按文件名或类型实时过滤；点文件弹出「预览 / 发送到聊天 / 下载到本地」操作菜单；右上角「+」为上传占位。
15. 通话：聊天页右上角点电话 / 视频进入通话页——「正在呼叫」约 2 秒后自动接通并开始计时，可切静音、免提（视频模式为摄像头开关），点红色挂断结束并返回聊天页；视频模式为城市夜景背景 + 右上角「我」的小窗。
16. 群公告：群资料页的公告卡、聊天页顶部的公告条都可以点进详情——完整正文、发布人与时间、已读进度条、点赞数；点「我已知晓」会变成灰色「已知晓」并把已读 +1，右侧「复制公告」写入剪贴板。
17. 查找聊天记录：群资料页「查找聊天记录」进入——输入关键词实时高亮命中文字，可按文本 / 图片 / 文件 / 语音筛选，点常用搜索词一键填充；演示数据含最近消息与「更早」的历史记录。
18. 我的收藏：我的页八宫格「我的收藏」进入——全部 / 图片 / 文件 / 链接 / 语音分类，图片点开是大图预览，文件支持预览 / 转发 / 取消收藏，语音点一下有播放波纹，左滑可删除收藏。
19. 群管理：群资料页底部「群管理」进入——改群名（同步消息列表与聊天页标题）、「全员禁言 / 入群审批」开关（状态回显群资料）、管理员头像行、群成员管理 / 群公告 / 群文件入口、转让群主与退出群聊；顶部群名整行也可点击改名。
20. 成员管理模式：群管理页「群成员管理 / 管理 / 添加」进入管理模式——点成员弹出底部面板：查看资料、设为管理员 / 取消管理员、移出群聊（二次确认后群人数 −1 并从列表移除）；顶部「完成」退出管理模式。
21. 群互动入口：群资料页新增「群互动」四宫格（群待办 / 群投票 / 群相册 / 群签到），群管理页也有一块同款入口，带待办数、进行中投票数角标和签到状态。
22. 群待办：列表按全部 / 待完成 / 已完成 / 我发起的筛选；点左侧圆圈标记完成（完成人数和进度条实时变化）；右上角「+」发布待办（内容 + 截止时间）；自己发起的待办可点「…」删除。
23. 群投票：进行中 / 已结束分栏；点选项直接投票，票数、百分比、进度条和「已投票」标记实时更新，每人限一票；右上角「+」发起投票（2~5 个选项）；自己发起的投票可在卡片底部「结束投票」，结束后进入已结束分栏并标记领先项。
24. 群相册：顶部相册封面横向切换，下方 3 列照片墙；点照片调用系统大图预览；「+ 新建相册」（名称 + 封面），相册内「添加照片」可继续加演示图，相册数量 / 照片总数同步更新。
25. 群签到：点「立即签到」后连续天数 +1、今日签到人数 +1、我的累计 +1，本周打卡点亮当天，签到榜把自己插到榜首并显示「我」；当天重复点击会提示已签到。
26. 卡片发到群聊：群待办每张卡右下角、群投票卡片底部、群签到页「分享今日打卡到群聊」都可以把对应内容发成一张群卡片消息；发送后可选择「去看看」直接跳到群聊。
27. 聊天群卡片：群聊里的待办 / 投票 / 签到卡片是独立消息类型，显示标题、状态和「点击查看详情」，点整张卡会分别跳回群待办 / 群投票 / 群签到；消息列表预览同步显示「[群待办] 标题」。产品设计组聊天里已预置一条群待办卡片可直接点。
28. 细节收尾：群待办 / 群投票首次进入有 420ms 骨架屏；成员、群文件搜索无结果和群待办 / 投票 / 相册空列表统一使用「qq-empty」空状态；所有页面切换带淡入转场（跟随系统「减少动态效果」）；≤375px 小屏自动收紧间距，群互动页底部补了安全区留白。
29. 演示数据持久化：发消息、加好友、改群名 / 禁言、勾选待办、投票、签到、发动态等操作都会在 160ms 后写入本地快照，刷新页面继续保留；「设置 → 演示数据 → 重置演示数据」二次确认后清空快照、关掉深色模式并刷新回消息页，登录态不变。
30. 草稿保存：聊天输入框里打字但没发送，退回消息页会显示「[草稿] 内容」；重新进入会话自动回填输入框，刷新页面也还在，发送后自动清空。
31. @我提醒：产品设计组里预置一条「林嘉禾 @江屿」消息，消息列表显示「@我」红色小标；进群后顶部出现「有人在群聊中@了你」提醒条，点提醒条定位到那条消息，点「知道了」收起。群里发「在吗」或带 @ 的文字，对方回复时会带上 @我，提醒条会再次出现。
32. 红包与转账：聊天「+」面板里的红包 / 转账会打开金额面板，支持快捷金额和留言；发出的红包卡片显示「等待对方领取」。产品设计组预置苏晚的奶茶红包（¥18.88），点卡片弹出红包详情，点「开」后变成「已存入零钱」并把聊天卡片标记为已领取。郑一诺单聊预置一笔 ¥52.00 转账，点开可「确认收款」；群聊里点转账会提示改用红包。
33. 视频消息：产品设计组预置苏晚的 15 秒露营视频，聊天里显示封面、播放键和时长；点开是全屏模拟播放器，有暂停 / 继续和进度条。自己也可以在「+」面板发视频，连续发送会轮换 3 段演示封面。
34. 消息多选：长按任意消息 →「多选」进入多选模式，标题变成「已选择 N 条」，每条消息左侧出现圆形勾选点；点消息行可继续加选或取消，点右上角「取消」退出。多选时红包、视频、图片等卡片不会再触发原有点击行为。
35. 批量删除：多选后底部出现「已选 N 条 / 转发 / 删除」操作栏；点「删除」弹出二次确认，确认后批量移除并同步刷新消息会话预览。
36. 批量转发：多选后点「转发」弹出会话列表（自动排除当前会话），点任意好友或群聊即可把这批消息以我的身份转发过去；文本、图片、语音、视频、群卡片、红包、转账都会保留原类型，引用和 @ 状态不随转发带走。
37. 时间分组：消息按天插入日期条，同一天里与上一条间隔 5 分钟以上会补一个时间点；今天以外的消息按 `day` 字段显示「昨天 / 周一」等日期条。
38. 送达状态：自己发出的消息先显示「发送中…」，450ms 后变成「已送达」；单聊再等 900ms 变成「已读」，群聊停在「已送达」。
39. 未读分隔：进入带未读的会话时，在未读起点前插入「以下是 N 条新消息」分隔线，清空未读后本次打开仍然保留这条线。
40. 引用定位：引用消息发送后，点气泡里的引用块会滚到原消息并短暂高亮；原消息已撤回 / 删除时提示「原消息已撤回或不存在」。
41. 聊天记录搜索跳转：聊天页右上角搜索进入聊天记录，输入关键词后点任意结果会回到聊天页并定位、高亮那条消息；更早的归档消息会自动补进当前会话，单聊 / 群聊都支持。
42. 好友备注：资料页右上角「…」→「设置备注」，保存后资料卡标题、联系人列表、消息列表和聊天标题同步显示备注；留空恢复昵称。
43. 好友标签：资料页「编辑标签 / + 标签」或「…」→「管理标签」可多选或新增标签（最多 8 个）；联系人页顶部标签条可按标签筛选，例如只看「摄影」好友。
44. 删除好友：资料页「…」→「删除好友」二次确认后移除联系人关系和单聊会话，消息列表与未读角标同步减少；群成员身份不受影响，仍可在群成员列表找到他并重新添加。
45. 加好友：非好友的资料页（好友申请人、群里的陌生成员）只显示「同意好友 / 加好友」，同意后加入联系人并自动生成一条「你们已经是好友了」会话；新的朋友页点申请人头像或名字也能先看资料再处理。

## 想改成真实数据

- 数据都在 `src/qq/data.ts`，群互动演示数据在 `src/qq/group-activity.ts`，按 `types.ts` 里的结构替换即可。
- 本地演示快照的字段白名单、版本号和恢复逻辑在 `src/qq/persist.ts`；改结构后把 `VERSION` 加一即可让旧快照自动失效。
- 所有状态读写集中在 `src/qq/store.ts`：`sendMessage()` 里现在用 `setTimeout` 造自动回复，接后端时把这里换成接口调用/WebSocket 推送，并调用 `receiveMessage()` 更新会话。
- 路由跳转统一走 `src/qq/router.ts`，改页面路径只需改这里。

## 已知限制

- 深色模式基于 CSS 变量实现：主题色定义在 `src/styles/qq.scss` 的 `--qq-*`，深色值挂在 `html.qq-dark` 上。新增页面请用 `var(--qq-card)` / `var(--qq-text)` / `var(--qq-line)` 等变量，写死十六进制颜色就不会跟随换肤。
- 登录页、资料卡头部、QQ 空间头部保留品牌渐变（蓝 / 红蓝 / 蓝），不随深色模式改变。
- 桌面浏览器里消息菜单用「右键」触发（uni-app 的 `@longpress` 只响应触摸，鼠标长按不触发）；手机上为长按 480ms。
- 复制功能依赖浏览器剪贴板权限，首次可能需要在地址栏允许；被拒绝时会提示“复制失败”。
- `qq-tab-icon`、`qq-swipe` 依赖 H5 DOM（内联 SVG / 原生事件监听），目前只保证 H5 效果，未适配小程序/App 端。
- 头像、图片、表情均为本地 mock；未做真实登录与后端同步，演示进度只保存在当前浏览器 localStorage 中。
- 语音 / 视频通话为纯界面演示：固定 2.2 秒后「接通」并本地计时，不采集麦克风 / 摄像头，也没有真实音视频流。
- 视频消息没有真实 mp4 素材：卡片和播放器用本地封面图 + CSS 进度条模拟，播放 / 暂停只控制进度动画，不加载音视频。
- 红包 / 转账为交互演示：金额、领取状态只存在本地 store 与快照里，不接支付，也不会产生真实资金变动。
- 批量转发只在本地会话之间复制消息，目标会话未读按现有 `appendMessage` 逻辑归零，不模拟服务端转发记录或转发回执。
- 消息时间分组只解析现有 demo 的 `HH:mm` 文本并配合手写 `day` 字段，没有接入真实时间戳；跨年 / 跨月排序需要换成 Date 字段。
- 聊天记录里更早的归档消息点开后只补进当前会话的内存数组，未写入持久化快照；刷新或重置后回到原来的最近消息列表。
- 资料页的「加好友」是演示捷径：没有真正发起等待验证的申请，确认后直接通过并建会话；好友申请仍以「新的朋友」里的待处理列表为准。
- 删除好友会移除联系人关系和单聊会话，历史消息仍留在内存缓存里但不再展示；重新添加会新建会话，不会恢复旧聊天记录。
