# DESIGN.md

## 气质与意象

- 关键词：午夜终端书房、磷光绿 CRT、黑客宝典、工具感。
- 具象场景：凌晨的机房里，一台老式终端亮着磷光绿的字符，机械键盘嗒嗒作响，桌上一本翻旧的 Node.js 宝典。整套界面像一块被点亮的绿色荧光屏，内容即代码、代码即内容。
- 第一直觉校验：Node.js 品牌色本身就是绿色（官方 Logo 绿），用绿做唯一强调色符合产品心智；刻意避开"科技蓝 + 蓝紫渐变 + 大圆角卡片"的万能组合，改为 1px 细边框 + 小圆角（4-6px）的工具风。

## 视觉策略

- 纯文档工具界面：左侧固定目录 + 右侧长文阅读区，信息密度高、留白克制。
- 代码是绝对主角：代码块使用比页面更深的底色（近纯黑），配 GitHub Dark 系语法配色，高对比。
- 无插画、无照片、无表情符号；图标全部为细线 SVG。
- 章节编号使用等宽字体的绿色数字（01 ~ 16），强化"宝典目录"的仪式感。

## Design Tokens

### 色彩
- 页面底色 `--bg: #0a0e0c`（近黑墨绿，CRT 关机色）
- 面板 `--bg-elev: #0f1512`；代码块 `--bg-code: #060907`（更深一层）
- 边框 `--border: #1d2822`；悬浮边框 `--border-hover: #2f4034`
- 正文 `--text: #d9e6dd`；次要文字 `--text-dim: #8aa394`
- 强调色 `--accent: #4ade80`（磷光绿，源自 Node 品牌绿 + 荧光屏）；弱化 `--accent-dim: #2e9e5b`
- 荧光底 `--accent-glow: rgba(74, 222, 128, 0.12)`
- 琥珀警示 `--amber: #e2b34a`（版本徽章 / 警告）
- 语法配色（代码块内）：关键字 `#ff7b72`、字符串 `#a5d6ff`、函数 `#d2a8ff`、数字与属性 `#79c0ff`、类型 `#ffa657`、注释 `#7d9084`、常量 `#79c0ff`

### 字体
- 代码 / 签名 / 编号：`JetBrains Mono`（Google Fonts CN 域名加载），兜底 `ui-monospace, Menlo, Consolas`
- 正文：`Noto Sans SC`，兜底系统中文栈（PingFang SC / Microsoft YaHei）
- 排版节奏：正文 15px / 行高 1.75；标题紧凑（h3 18px）；代码 13.5px / 行高 1.6

### 圆角与阴影
- 圆角统一 4-6px，按钮 4px，代码块 8px
- 不使用投影堆砌，层级靠底色深浅 + 1px 边框区分

### 动效
- 性格：快、干脆、克制，像终端光标跳动
- 统一过渡 `140ms cubic-bezier(0.2, 0, 0, 1)`
- 光标闪烁：`blink 1s steps(2) infinite`
- 目标 API 定位：`flash 1.6s`（绿色荧光底渐隐）
- 终端输出：提示符逐字打出，输出行逐行浮现（`fade-up 220ms`）

## 布局与响应式

- ≥1024px：侧边栏 272px 固定 + 内容区最大 860px 居中
- <1024px：侧边栏变为抽屉（汉堡按钮 + 遮罩），滑入滑出 240ms
- 代码块在窄屏横向滚动，不换行折断

## 设计禁忌

- 不使用蓝紫色渐变、玻璃拟态彩色光晕
- 不使用大面积圆角卡片堆砌与投影
- 不使用表情符号、彩色插画
- 除强调绿与琥珀警示外，不引入第三种彩色
